{# Press — HubDB dynamic page template, styled with "Theme: BASE" design. This single template serves two views, both backed by the `press` HubDB table: - Listing view (default): a filterable, paginated list of press mentions, each linking out to the mention's on-site detail page. - Detail view: rendered automatically by HubSpot whenever this page is configured as a HubDB dynamic page for the `press` table and the request matches a row's `path` (exposed here as `dynamic_page_hubdb_row`). Design: matches BASE (the marketplace theme used by truedoors.com's other real pages, e.g. /testimonials) rather than this repo's own "True Doors Theme" styling. BASE's Design Manager source is 403-blocked for marketplace themes, so instead: - `{% global_partial %}` renders BASE's actual global header/footer content at request time. - BASE's *compiled* CSS is linked directly from its public, hashed CDN URLs (template_main.css + module_blog-listings.min.css). These URLs have no official pinning guarantee — if BASE is updated in HubSpot, re-fetch them from a live BASE page's if styling breaks. - Brand colors/typography not exposed as BASE CSS variables were sampled from truedoors.com and declared in css/press-base-design.css. See true-doors-theme/templates/press-mockup.html (the original design preview at /press-design-mockup) for the design rationale/history. Setup required outside of this repo (HubDB dynamic pages are a content-tool setting, not something a theme file can express on its own): 1. Run scripts/backfill_press_slugs.js once so every `press` row has a unique path (required for per-row detail URLs). 2. In HubSpot: Content > Pages > create a page using this template, then under Advanced Options enable "Make this an HubDB dynamic page" and select the `press` table. Publish the page at the path referenced by `press_base_path` below (defaults to "/press").
